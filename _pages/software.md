Selected public software projects to which I contributed.

## Opticore Inference Explorer

An interactive tool showing how photonic computing can reduce the energy and cost of running large AI models.

I contributed to this project while interning at [Opticore](https://www.opticore.ai/).

[Open the Inference Explorer](https://www.opticore.ai/explorer){: .btn .btn--primary }

## DNALinux AI (Takollama)

An open-source retrieval-augmented generation system for bioinformatics software documentation. It uses Ollama and Chroma to ingest content from PDFs, HTML files, and web pages, then answer questions using retrieved context.

I contributed to this project while interning at [Toyoko](https://www.toyoko.io/).

[View the project on GitHub](https://github.com/DNALinux/ai){: .btn .btn--primary }
